## Цель модели

Модель предназначена для автоматической сегментации биомаркеров на фотографиях глазного дна: определения областей изображения, соответствующих 14 целевым классам, включая друзы, кровоизлияния, экссудаты, микроаневризмы и другие изменения сетчатки.

На вход модель получает подготовленные фрагменты снимка размером 512 × 512 пикселей. Результат работы — маска, в которой каждому пикселю присвоен один из 14 классов биомаркеров либо фон.

**Бизнес-задача:** автоматизировать предварительное выделение областей биомаркеров для последующего анализа специалистом. Предполагаемая польза — сокращение объёма ручной работы при анализе и разметке снимков.

Текущее назначение — исследовательское использование и разработка методов анализа изображений глазного дна. Модель не предназначена для самостоятельной постановки диагноза или назначения лечения.


## Метрики

Качество сегментации модели SegFormer оценивается по двум метрикам:

| Метрика | Назначение |
|---|---|
| Dice | Степень совпадения предсказанной маски с эталонной разметкой |
| Recall | Доля правильно обнаруженных пикселей биомаркера среди всех его пикселей в эталонной разметке |

### Протокол оценки

Оценка проводилась методом трёхфолдовой кросс-валидации на наборе из 1822 изображений и 5196 патчей. На каждом этапе два фолда использовались для обучения, третий — для валидации.

Метрики рассчитывались для 14 классов биомаркеров без учёта фона. Отсутствующие классы получали нулевые значения и учитывались при усреднении. Результаты представлены как **среднее значение ± стандартное отклонение** по трём фолдам.

### Показатели качества

Для SegFormer с функцией потерь **Cross-Entropy + 2 × Tversky Loss** получены следующие средние показатели по 14 классам:

| Dice | Recall |
|---|---|
| 0,648 ± 0,012 | 0,669 ± 0,011 |

## Ограничения

- **Пропуск мелких и редких биомаркеров.** Наиболее низкая полнота сегментации наблюдается для микроаневризм и венозных аномалий: Recall составляет 0,43 и 0,22 соответственно. Результаты для этих классов требуют особенно внимательной проверки специалистом.

- **Ограниченный состав данных.** Обучение и оценка выполнены на одной клинической выборке. Внешняя валидация на данных других медицинских организаций не проводилась.

- **Ограниченный пространственный контекст.** Обработка выполняется на патчах размером 512 × 512 пикселей, поэтому доступный модели контекст ограничен границами фрагмента. Качество сегментации полных снимков отдельно не оценивалось.

- **Зависимость от условий съёмки.** Устойчивость к различиям в оборудовании и условиях получения изображений не оценивалась. Применение на данных из новых источников требует дополнительной валидации.

- **Ограничения клинического применения.** Модель предназначена для предварительного выделения биомаркеров с последующей проверкой специалистом. Самостоятельная постановка диагноза и назначение лечения не входят в её назначение. Отсутствие выделенного биомаркера не означает отсутствия патологии.

## Bias/Fairness анализ

Качество модели неодинаково для разных классов биомаркеров. Наиболее высокие показатели достигаются для макулярного отверстия и географической атрофии, наиболее низкие — для микроаневризм и венозных аномалий.

### Возможные источники смещения

- **Дисбаланс классов.** Неравномерная представленность биомаркеров затрудняет обучение на редких классах и может приводить к их пропуску.

- **Размер патологических областей.** Мелкие биомаркеры занимают небольшую часть изображения и сложнее выделяются на фоне окружающих структур. Качество их сегментации ниже, чем для ряда крупных патологических областей.

- **Отбор данных.** Исключение патчей без биомаркеров и предпочтение областей с большим количеством пикселей целевого класса смещают выборку в сторону изображений с выраженными патологическими изменениями.

- **Один источник клинических данных.** Особенности пациентов, оборудования и условий съёмки одной клинической выборки могут ограничивать переносимость модели на другие группы и источники изображений.

### Оценка справедливости

Отдельная оценка качества по возрасту, полу и другим демографическим характеристикам пациентов не проводилась. Равномерность качества между этими группами не установлена.

Различия метрик между классами биомаркеров характеризуют качество сегментации отдельных патологий, но не заменяют оценку справедливости по группам пациентов.

### Снижение влияния дисбаланса

При обучении используется функция потерь **Cross-Entropy + 2 × Tversky Loss**. В компоненте Tversky ложноотрицательные ошибки имеют вес 0,7, ложноположительные — 0,3. Это усиливает штраф за пропуск пикселей биомаркеров, однако не устраняет различия качества между классами и не гарантирует одинаковое качество для разных групп пациентов.

### Подготовка выборки

- Исключены патчи без биомаркеров.
- Количество патчей ограничено тремя на одно исходное изображение.
- При наличии более трёх подходящих патчей отбирались области с наибольшим количеством пикселей целевого класса.
- Одно изображение исключено из-за отсутствия биомаркеров.
